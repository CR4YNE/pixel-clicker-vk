# Политика конфиденциальности игры «Куча Пряников: Кликер»

## 1. Кто обрабатывает данные

Оператор персональных данных: CR4YNE. Контакты: cr4ynegames@gmail.com, billkamikadze@gmail.com, сообщество [CR4YNE GAMES](https://vk.ru/club243526817).

## 2. Какие данные обрабатываются

2.1. Идентификатор пользователя VK (user_id), который VK передаёт при запуске игры в параметрах запуска. Используется только для сохранения прогресса в облачном хранилище VK.

2.2. Игровой прогресс: количество пряников, купленные улучшения и технику, прогресс достижений, настройки звука и громкости, статистику игры (время, клики, покупки). Эти данные не содержат имени, почты, номера телефона или адреса.

2.3. Сведения о покупках и просмотре рекламы: факт покупки и факт просмотра награды. Платёжные данные обрабатывает VK, Разработчик их не получает.

## 3. Где хранятся данные

3.1. Прогресс хранится на устройстве в браузере (localStorage) и в облачном хранилище VK Storage, привязанном к user_id. Так прогресс виден на разных устройствах.

3.2. Данные хранятся до тех пор, пока вы не удалите прогресс или аккаунт, либо пока вы не запросите удаление.

## 4. Цели обработки

4.1. Сохранение прогресса, работа Игры на разных устройствах, учёт покупок и наград, работа поддержки.

4.2. Разработчик не использует данные для рекламы, не передаёт их третьим лицам и не продаёт.

## 5. Передача третьим лицам

5.1. Данные передаются VK в объёме, необходимом для работы Игры (хранение прогресса, платежи голосами, реклама VK Ads). Политика VK доступна на сайте VK.
